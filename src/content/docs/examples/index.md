The examples live in the [Spool-FRAMEWORK-Labs](https://github.com/Spool-FRAMEWORK-Labs) organization, one repository per pipeline.

| Example | What it shows | Spool version |
| --- | --- | --- |
| [SEC EDGAR filings](/examples/sec-edgar/) | A poll source written for a public API, and records mapped to a Java class. | 1.4.0 |

The other pipelines in Labs (the Spanish official gazette, electricity market data from Red Eléctrica and synthetic health records) still target older versions of Spool and are not documented here yet.

For a pipeline described as an application rather than as code you can run, see [Keep an assistant's knowledge base up to date](/use-cases/assistant-knowledge-base/).
